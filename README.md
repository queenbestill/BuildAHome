# Build a Home

Website for the *Build a Home* campaign: a phone-free space for meditation, rest and presence.

Built with Next.js and Tailwind CSS. All the site copy lives in `data/portfolio.json`; the blog posts ("Updates") live in `_posts/`.

## Run it locally

```bash
yarn
yarn dev
```

Open http://localhost:3000.

## Deploy

The site is deployed on Vercel. Every push to the main branch publishes automatically.
